# Toi's Armory

![Minecraft Version](https://img.shields.io/badge/Minecraft-26.2-brightgreen.svg)
![Data-Driven](https://img.shields.io/badge/System-Data_Driven-blue.svg)

[👉 **Read in English**](README.md)

Toi's Armory は、データ駆動システムで設計された多機能かつ軽量な銃データパックです。
データパックとリソースパックのみで、固有の反動パターン、ADS（エイム）、距離によって遷移するダメージ計算、アタッチメントシステムなどのリアルなガンファイトを、高いパフォーマンスを維持したまま実現します。

**注意: このデータパックは現在 Minecraft 26.3 のみで動作します。**

## ✨ 主な機能

- **豊富な銃のメカニクス**
  - **物理的な弾道計算**: 弾速と重力を持つ弾丸。距離に応じてダメージが遷移します。
  - **リコイルと視点ブレ**: 銃ごとに設定された固有の反動パターン。呼吸によるブレや発砲による精度低下も再現されます。
  - **動的なリロード処理**: 薬室に弾が残っている状態と弾切れの状態で、リロード時間やアニメーションが変化します。
  - **高精度な当たり判定**: `Bookshelf` ライブラリの `Hitbox` モジュールを使用し、DDAレイキャストによる精密な当たり判定を行っています。
- **アタッチメントシステム**
  - サイト、バレル、グリップなどをカスタマイズ可能。アタッチメントの装着により、ADS速度、反動の強さ、銃のブレなどの性能が変化します。
- **データ駆動のアドオンシステム**
  - ロード時に `toisarm:import` ストレージへNBTデータを追加するだけで、誰でも簡単に独自の銃を追加できます。
  - アニメーションのフレーム、サウンドの再生タイミング、反動、距離によるダメージ遷移、アタッチメントの設定など、すべてSNBTで設定可能です（同梱の `default_gunpack` フォルダが参考になります）。

## 🎮 操作方法

デフォルトの操作方法は以下の通りです（ダイアログメニューから変更可能です）。

- **右クリック**: 射撃
- **左クリック**: エイム (ADS)
- **オフハンド切り替え (初期: F)**: リロード
- **アイテムを捨てる (初期: Q)**: 射撃モード切替 (フルオート/セミオートなど)
- **ダイアログメニュー (初期: G)**: 設定や管理のためのダイアログを開きます。
  - 操作キーの割り当て変更。
  - アタッチメントの着脱・編集。
  - (OP権限のみ) 管理者メニューから銃やアタッチメントを取得可能。

## 📦 導入方法
1. **データパック** と **リソースパック** の両方をダウンロードします。
2. データパックをワールドの `datapacks` フォルダに入れます。
3. リソースパックを `.minecraft/resourcepacks` フォルダに入れ、ゲーム内で適用します。
4. ワールドに入るか、すでにワールドに入っている場合は `/reload` コマンドを実行してください。
